3. INTERNAL SESSION & RECORDING ORGANIZATION (QUESTION 2)

Each session is stored in a root directory named after its numeric `AufnahmeID`
(e.g., `data/raw/laryngozele/1205/`).

Directory Structure within a Session:
  `<AufnahmeID>/`
    ├── `vowels/`     (Contains sustained vowel phonations)
    ├── `sentences/`  (Contains continuous speech phrase recording)
    └── `remarks/`    (Optional: phonetician notes in .txt, present in 168 sessions)

Audio and Signal File Pairs:
  Every acoustic recording (`.nsp`) has a companion electroglottography (`.egg`)
  file with identical naming and synchronized duration.

Standard Session Inventory (14 NSP + 14 EGG = 28 files):
  1. Sustained Vowels (13 files in `vowels/`):
     - /a/: `{id}-a_n.nsp` (normal), `{id}-a_l.nsp` (low), `{id}-a_h.nsp` (high), `{id}-a_lhl.nsp` (gliding: low-high-low)
     - /i/: `{id}-i_n.nsp` (normal), `{id}-i_l.nsp` (low), `{id}-i_h.nsp` (high), `{id}-i_lhl.nsp` (gliding: low-high-low)
     - /u/: `{id}-u_n.nsp` (normal), `{id}-u_l.nsp` (low), `{id}-u_h.nsp` (high), `{id}-u_lhl.nsp` (gliding: low-high-low)
     - Continuous Vowel Sequence: `{id}-iau.nsp` (/i-a-u/ continuous gliding)
  2. Continuous Speech Phrase (1 file in `sentences/`):
     - Standard German diagnostic sentence: `{id}-phrase.nsp`

4. METADATA FIELDS IN OVERVIEW.CSV (QUESTION 3)
--------------------------------------------------------------------------------
The `overview.csv` files in all three class folders share the identical 8-column
schema:

  1. `AufnahmeID`   [Integer]:
     Unique Recording / Session ID (matches the folder name on disk).
  2. `AufnahmeTyp`  [String]:
     Recording type code: 'p' = pathological, 'n' = normal / healthy control.
  3. `AufnahmeDatum` [Date, YYYY-MM-DD]:
     Date on which the acoustic session was recorded.
  4. `Diagnose`      [String, Free text]:
     Clinical diagnosis description in German (e.g., "Mit Stimmschwäche",
     "Zustand nach Abtragung"). Empty for normal controls.
  5. `SprecherID`   [Integer]:
     Unique Patient / Speaker ID. Critical field for group-based data splitting.
  6. `Geburtsdatum`  [Date, YYYY-MM-DD]:
     Date of birth of the patient. Combined with `AufnahmeDatum`, this enables
     exact decimal age calculation at the time of recording.
  7. `Geschlecht`    [String, 'm' / 'w']:
     Biological sex: 'm' = männlich (male), 'w' = weiblich (female).
  8. `Pathologien`   [String]:
     Standard pathology classification tag (e.g., "Laryngozele", "Vox senilis",
     or blank for healthy controls).

5. DATA LEAKAGE ANALYSIS & TRAIN/VAL/TEST SPLITTING (QUESTION 4)
--------------------------------------------------------------------------------
Can metadata be used to create splits and prevent data leakage?
YES, the metadata is fully sufficient, but standard naive random splitting will
CAUSE SEVERE DATA LEAKAGE and CONFOUNDING BIAS.

Key Leakage Vectors & Solutions:

  A. File-Level Leakage (Intra-Session Leakage):
     - Each session contains up to 14 audio files. If files are randomly split,
       different pitch recordings from the same person will be present in both
       train and test sets.
     - Solution: NEVER split at the audio file level.

  B. Session-Level vs. Patient-Level Leakage:
     - 6 speakers in the dataset have multiple recording sessions across dates.
     - If splits are grouped by `AufnahmeID` (session), the same patient's voice
       will leak into both train and test.
     - Solution: Grouping MUST be performed strictly on `SprecherID`.

  C. Cross-Class Patient Contamination:
     - Speaker 73 is present in both Normal and Vox Senilis.
     - Solution: Speaker 73 must be quarantined, assigned exclusively to one
       split partition, or excluded from the evaluation set to prevent
       contradictory ground truth targets for the same vocal anatomy.

  D. Severe Demographic Confounding (Age and Gender Bias):
     - Vox Senilis patients are elderly (mean age 73.3 years).
     - Normal controls are predominantly young university students (mean age 27.9).
     - A machine learning model trained naively on raw acoustic features will
       inadvertently classify *chronological age* rather than *pathology*.
     - Solution: Normal controls should be age- and gender-matched or stratified
       using `Geburtsdatum`, `AufnahmeDatum`, and `Geschlecht` metadata.

  E. Extreme Class Imbalance:
     - Class distribution: Laryngozele (3) vs. Vox Senilis (39) vs. Normal (681).
     - With only 3 Laryngozele patients, standard 70/15/15 random splitting is
       statistically invalid (only 1 sample per split or 0 in test).
     - Solution: Leave-One-Patient-Out Cross-Validation (LOPO-CV) or Stratified
       Group K-Fold with specialized few-shot / anomaly-detection evaluation.
